Mandatory Fields by Document State

Prevent users from confirming or posting documents when key information is missing. Configure required fields by model and state.

Supported documents (MVP)

  • Sales Orders (sale.order)
  • Purchase Orders (purchase.order)
  • Invoices / Journal Entries (account.move)

Configuration

  1. Mandatory Fields → Rules
  2. Create a rule and set mandatory field technical names (comma-separated)
  3. On confirm/post, users will see a clear error when fields are missing
