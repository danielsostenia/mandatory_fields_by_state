Mandatory Fields by Document State

Stop Sales Orders, Purchase Orders and Invoices from being confirmed or posted while key information is missing — without a line of code.

One rule per document type · Clear error message · Set up in 2 minutes

✅ Pick the fields

Choose any field of the document — customer reference, delivery date, payment terms, analytic account, salesperson, custom fields… — from a simple list.

🎯 Only where it matters

Limit a rule with a filter: only customer invoices, only one company, only orders above an amount, only a sales team. Everything else works as before.

🛑 Blocked at the right moment

Drafts can be saved freely. The check runs when the order is confirmed or the invoice is posted, and the message lists exactly what is missing.

⚙️ Safe for automated flows

Scheduled actions, online payments and stock valuation are not interrupted by default. Turn on Enforce on Automated Flows on a rule when you want them checked too.

What the user sees

Validation Error
Please fill in all mandatory fields before confirming/posting.
Missing: Customer Reference, Delivery Date

The first line is your own message, set on each rule.

Where the rules apply

Document Checked when
Sales Order / Quotation it is confirmed
Purchase Order / RFQ it is confirmed
Customer Invoice, Vendor Bill, Credit Note it is posted (including reversals)

Typical rules

  • Vendor bills must have a Bill Reference and a Bill Date
  • Sales orders must have a Customer Reference and a Delivery Date
  • Purchase orders must have a Buyer and an Expected Arrival
  • Customer invoices must have Payment Terms

Setup in 3 steps

  1. Add your user to the Mandatory Fields Manager group.
  2. Activate developer mode and open Settings → Technical → Mandatory Fields → Rules.
  3. Create a rule: document type, mandatory fields, optional filter and message. Done.

Features

  • Rules for Sales Orders, Purchase Orders and Invoices / Journal Entries
  • Any field of the document, including custom fields
  • Optional filter (domain) per rule, with a safe default for journal entries
  • Custom error message per rule; the missing fields are always listed
  • Several rules per document type; archive a rule to switch it off
  • Automated flows skipped by default, enforceable per rule
  • Dedicated access group: only managers can change the rules

Requirements

Odoo 18 Community or Enterprise, on Odoo.sh or on-premise, with the Sales, Purchase and Invoicing apps.
